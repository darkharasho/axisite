AxiAM is a desktop account launcher focused on speed, security, and clean multi-account workflow. Credentials are encrypted locally with a master password, and each account can be added, edited, and organized with its own launch options, then started through Steam integration with clear running/launching/stopping status. It also supports optional GW2 API key lookups to resolve account profile metadata in the UI.
