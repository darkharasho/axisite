arcdps wiki is a community-managed wiki and technical reference for arcdps, the Guild Wars 2 combat-analysis addon. It's built with Astro and Starlight, edited entirely through GitHub pull requests with no in-browser editor or live database, and deployed under the `axi.link` domain. The repo covers the docs site itself plus a hand-seeded technical reference for arcdps' extension API, data structures, enums, and exports.
