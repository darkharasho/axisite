axi-design is the design language for the axi suite — flat and outlined, dark, drawn in saturated ink. It ships as a single CSS file with no build step for consumers, no dependencies, and no JavaScript: link the stylesheet, set one accent custom property, and the whole theming surface is done. A set of per-instance knobs, like grid column width or card strip color, cascade from any ancestor element without being theme tokens, and a live pattern gallery documents every component.
