AxiCode is a compact binary encoder/decoder for Guild Wars 2 builds and team compositions, producing shareable strings in the AxiCode format used by AxiForge. It supports two code types: build codes, a single character build with profession, specializations, traits, skills, and equipment; and comp codes, a full team composition with multiple builds and party lines. It ships as an npm package with functions to encode, decode, and validate both formats.
